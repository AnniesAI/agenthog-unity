# agenthog-unity

[AgentHog](https://github.com/AnniesAI/agent-hog) analytics for Unity games.

- **[`com.brightmotion.agenthog/`](com.brightmotion.agenthog/)** — the UPM package games
  install. Sessions, automatic scene pageviews, uGUI click autocapture, per-screen time,
  custom events, identity, offline carry-over. Pure C#, zero dependencies, no native code.
  **Start with its [README](com.brightmotion.agenthog/README.md).**
- **[`ExampleGame/`](ExampleGame/)** — a tiny three-scene game (menu → tap-the-target →
  results) exercising the whole SDK surface. Open it in Unity 6, press Play. It ships with
  a blank AgentHog config (SDK inert); to send real events, create
  `Assets/Resources/AgentHogSettingsLocal.asset` (gitignored) with your host + project key.

## Install (in your game)

```json
"com.brightmotion.agenthog": "https://github.com/AnniesAI/agenthog-unity.git?path=com.brightmotion.agenthog#v0.1.0"
```

## Development

- Edit-mode tests live in the package (`Tests/`); ExampleGame is the test host:
  `scripts/run-tests.sh 6000.5.7f1` (any installed Unity version works; pre-6000 editors run
  against a scratch-downgraded copy under `out/`).
- `Tests/Fixtures/golden-batch.json` is the wire-format anchor. The agent-hog repo validates
  the same fixture against its real ingest parser (`scripts/check-unity-contract.test.ts`
  there), so regenerate it only for intended contract changes (`AGENTHOG_UPDATE_GOLDEN=1`)
  and re-run that check.
- Example scenes are generated by `ExampleGame/Assets/Editor/SceneBuilder.cs`
  (menu: *AgentHog → Rebuild Example Scenes*).
